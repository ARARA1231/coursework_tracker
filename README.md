# Учёт курсовых работ

## Назначение

Приложение для учёта курсовых работ. Оно помогает отслеживать, какой
студент выполняет курсовую работу, кто является её руководителем,
на каком этапе находится работа и сколько времени осталось до срока сдачи.

## Целевая аудитория

- преподаватели — руководители курсовых работ;
- студенты, выполняющие курсовые работы;
- сотрудники учебного отдела.

## Предметная область

Студент выполняет курсовую работу под руководством преподавателя.
У работы есть тема, срок сдачи, статус и оценка. Работа проходит этапы
«в работе» → «на проверке» → «защищена». Преподаватель может руководить
ограниченным числом студентов. У студента может быть только одна
активная курсовая работа.

## Основные сущности

- **Студент** — ФИО, учебная группа, электронная почта;
- **Преподаватель** — ФИО, кафедра, электронная почта,
  максимальное число студентов;
- **Курсовая работа** — тема, студент, руководитель, срок сдачи,
  статус, оценка.

## Основные функции

- проверка, может ли преподаватель взять ещё одного студента;
- расчёт количества дней до срока сдачи работы;
- предупреждение о приближении или нарушении срока сдачи;
- вывод описания текущего статуса курсовой работы.

## Запуск

```
python main.py
```

## План развития

На следующих этапах планируется:

- хранение данных в файлах, работа с наборами студентов,
  преподавателей и работ;
- реализация сущностей в виде классов;
- разработка веб-приложения на Django;
- подключение базы данных;
- реализация пользователей и разграничения доступа;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
